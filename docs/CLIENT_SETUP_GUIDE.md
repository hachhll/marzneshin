# Инструкция по установке и настройке VPN (`sing-box`)

> **Важно:** Используйте **только** указанные ниже официальные клиенты и **только** выданный вам `.json`-файл.
> - Не используйте сторонние приложения (`v2rayTun`, `Streisand`, `Shadowrocket`, `v2rayNG` и т.п.) и не добавляйте ссылки вручную.
> - Не меняйте настройки внутри профиля (DNS, маршрутизацию, отпечаток браузера).

---

## 1. Android

### Шаг 1. Установите приложение `sing-box`
Нужен официальный клиент **`sing-box`** (версия **1.14 или выше**):
- **Google Play:** [sing-box (`io.nekohasekai.sfa`)](https://play.google.com/store/apps/details?id=io.nekohasekai.sfa)
- **GitHub (APK, если нет Google Play):** [SagerNet/sing-box-for-android Releases](https://github.com/SagerNet/sing-box-for-android/releases) (скачайте файл `SFA-*-universal.apk` и установите).

### Шаг 2. Сохраните выданный файл на телефон
Сохраните полученный `.json`-файл в папку **«Загрузки»** (Downloads) на телефоне:
- Для семьи/медиа: `android-media-selective.json`
- Для владельца: `android-singbox-selective.json` (избирательный режим) или `android-singbox.json` (весь трафик).

### Шаг 3. Импортируйте настройки
1. Откройте **`sing-box`**.
2. Нажмите **Profiles** (Профили) → кнопку **`+`** (Добавить) → **Create Manually** / **Local** → **Import from File** (Импорт из файла).
   *(В русской локализации: **Профили → + → Создать вручную / Локальный → Выбрать файл**.)*
3. Выберите скачанный `.json`-файл и нажмите **Create / Save** (Сохранить).
   - **Не выбирайте** «Remote» (Удалённый профиль по URL).
4. Нажмите на созданный профиль, чтобы сделать его активным.

### Шаг 4. Включите VPN
1. Перейдите на главный экран **Dashboard** (Панель).
2. Переведите переключатель **Enable** (Включить) в активное положение.
3. При первом запуске Android попросит разрешение на создание VPN-подключения — нажмите **ОК / Разрешить**.

### Что отключить на Android (важно для стабильной работы)
- В настройках телефона (особенно в профиле владельца) отключите **Геолокацию / Поиск сетей Wi-Fi и Bluetooth в фоне** и любые другие VPN/частные DNS (в «Частном DNS» Android должно быть **Авто** или **Выключено**, не сторонний DoH).

## 2. iOS (iPhone / iPad)

### Шаг 1. Установите приложение `sing-box MT`
Нужен **только** официальный клиент **`sing-box MT`** (разработчик *Metamerism LLC*, версия **1.14 или выше**):
- **App Store:** [sing-box MT](https://apps.apple.com/app/sing-box-mt/id6670731039)
- *Примечание:* Если в российском App Store приложение скрыто, войдите в App Store под зарубежным Apple ID (например, США, Казахстан или Европа), установите `sing-box MT` и вернитесь в свой основной Apple ID.

### Шаг 2. Сохраните файл в «Файлы»
Передайте полученный `.json`-файл на iPhone (например, через AirDrop, Google Drive или мессенджер) и нажмите **«Сохранить в Файлы»**:
- Для семьи/медиа: `ios-media-selective.json`
- Для владельца: `ios-singbox-selective.json` или `ios-singbox.json`.

### Шаг 3. Разрешите VPN и импортируйте профиль
1. Откройте **`sing-box MT`**.
2. На главной панели (**Панель** / *Dashboard*) нажмите на ссылку/кнопку разрешения VPN-профиля и **разрешите** iOS добавление VPN-конфигурации (подтвердите через Face ID / Touch ID или код-пароль).
3. После этого на той же главной панели появится раздел **«Конфигурация»** (или перейдите во вкладку **Профили** / *Profiles*) — нажмите кнопку **`+`** для добавления профиля.
4. Выберите **Локальный** (*Local*) → **Импорт из файла** (*Import from File*) и укажите сохранённый `.json`-файл из приложения «Файлы».
   - Режим **Удалённый** (*Remote*) не используйте.
5. Нажмите **Создать** (*Create*) и убедитесь, что созданный профиль выбран активным.

### Шаг 4. Включите VPN и проверьте настройки iPhone
1. На вкладке **Панель** (*Dashboard*) переведите переключатель **Включить** (*Enable*) в активное положение (если iOS снова запросит разрешение — нажмите **Разрешить**).
2. Откройте **Настройки iPhone**:
   - **Apple ID → iCloud → Частный узел (Private Relay):** обязательно **выключите** (иначе возможны конфликты и утечки DNS).
   - **Основные → VPN и управление устройством → DNS:** убедитесь, что стоит **Автоматически**, без сторонних DNS-профилей (AdGuard DNS и т.п.).

## 3. Windows 11 (`Throne`)

### Шаг 1. Скачайте и установите клиент `Throne`
1. Перейдите на официальную страницу релизов: [throneproj/Throne Releases](https://github.com/throneproj/Throne/releases).
2. Скачайте последний архив для Windows (обычно `Throne-*-windows64.zip` или установщик `.exe`).
3. Распакуйте архив в удобную папку (например, `C:\Tools\Throne\`, чтобы путь не содержал кириллицы и лишних ограничений).
4. Запустите **`Throne.exe` от имени администратора** (правая кнопка мыши → *Запуск от имени администратора* — это нужно для работы системного TUN-режима).

### Шаг 2. Добавьте выданный профиль
Используется файл **`throne-windows11-selective.json`** (избирательный режим) или **`throne-windows11.json`** (полный туннель).
1. В окне `Throne` откройте меню импорта конфигурации (`Program / Profile → Import JSON` или перетащите JSON / вставьте его содержимое как **Custom Sing-box Config**).
2. Сохраните профиль под понятным именем и выберите его активным.

### Шаг 3. Включите режим TUN
1. В главном окне `Throne` обязательно включите галочку/переключатель **TUN Mode** (Режим TUN), чтобы весь нужный трафик и программы (браузеры, IDE, мессенджеры) работали через защищённый туннель, а не только через системный прокси.
2. Нажмите **Start** (или включите профиль) и разрешите доступ в Брандмауэре Windows, если появится запрос.
3. Отключите встроенный DoH («Безопасный DNS») в браузерах Chrome / Edge / Firefox, если он включён вручную — DNS уже управляется профилем.

## 4. OpenWrt (роутер)

> **Важно:** На роутер OpenWrt **нельзя** копировать файлы от телефона или Windows (`android-*.json`, `throne-windows11.json`) — они сломают локальный DNS (`dnsmasq`) и маршрутизацию (`fw4`), а тяжёлые списки могут переполнить оперативную память роутера.
> Кроме того, на домашнем роутере используйте **только избирательную маршрутизацию (`Selective`)** или отдельный VLAN для рабочих устройств — **не направляйте весь домашний Wi-Fi в `Full Tunnel` через рабочий AI-выход**.

### Вариант А (рекомендуемый): через `podkop` + `openwrt-outbound.json`

1. **Установите `podkop` на роутер:**
   - Подключитесь к роутеру по SSH (`ssh root@192.168.1.1`) и выполните установку по официальной инструкции репозитория [itdoginfo/podkop](https://github.com/itdoginfo/podkop) (или установите `.ipk` пакеты `podkop` и `luci-app-podkop` из [itdoginfo/podkop Releases](https://github.com/itdoginfo/podkop/releases)).
   - `podkop` автоматически установит ванильный **`sing-box`** и настроит его работу с `firewall4` (`nftables`) и `dnsmasq`.
2. **Подключите конфиг нашего моста (`openwrt-outbound.json`):**
   - Откройте веб-интерфейс роутера **LuCI → Services → Podkop** (или конфиг `/etc/config/podkop`).
   - В качестве пользовательского outbound вставьте **только секцию outbound** из выданного файла **`openwrt-outbound.json`** (не вставляйте полный конфиг).
   - Выберите нужные списки/домены в `podkop` (избирательный режим).
3. **Обязательные настройки безопасности на роутере:**
   - Отключите проброс/использование **IPv6** в локальной сети (или заблокируйте `::/0` в фаерволе для проксируемого трафика).
   - В настройках `dnsmasq` / `podkop` отключите ответы DNS типа **`HTTPS` (`SVCB`/`HTTP3`)**, а в `firewall4` заблокируйте исходящий **`UDP 443` (QUIC)** и **`UDP 3478, 19302` (STUN/WebRTC)** для устройств, идущих через туннель.
4. Перезапустите службу `podkop` и проверьте доступ с рабочего устройства.

### Вариант Б (без `podkop`): чистый сервис `sing-box` + `openwrt-singbox.json`

1. Установите пакет **`sing-box`** на OpenWrt (`opkg update && opkg install sing-box` или `apk add sing-box` на OpenWrt 24+/SNAPSHOT).
2. Скопируйте выданный роутерный файл **`openwrt-singbox.json`** в `/etc/sing-box/config.json`.
3. Настройте перенаправление нужного трафика с `br-lan` на `tproxy` порт из `openwrt-singbox.json` через `nftables` (`firewall4`) и убедитесь, что `UDP 443/3478/19302` и `IPv6` для туннелируемого трафика заблокированы.
4. Включите и запустите службу:
   ```sh
   /etc/init.d/sing-box enable
   /etc/init.d/sing-box restart
   ```
